# TodoDoneYet Examples

This directory contains example files demonstrating the TodoDoneYet Task File Format (`.tddy`).

## Files

### `basic-task.tddy`

A basic TodoDoneYet task demonstrating `DONE_YET` mode and common task fields.

### `modes.tddy`

An example demonstrating a task using `RELENTLESS_MODE`.

### `simple-mode.tddy`

An example demonstrating `SIMPLE_MODE` with the optional `anchor` field omitted.

## Using the Examples

These files can be opened as plain text and used as references when creating `.tddy` files.

For the complete format definition, see the [TDDY Format Specification](../TDDY_FORMAT_SPECIFICATION.md).

For machine-readable validation, see the [JSON Schema](../schema/tddy.schema.json).
