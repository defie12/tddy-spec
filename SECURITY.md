# Security Policy

## Reporting a Security Issue

If you discover a security issue related to the TodoDoneYet Task File Format, JSON Schema, or reference implementation, please report it privately rather than publicly disclosing the issue.

When reporting an issue, include:

- A clear description of the issue
- Steps to reproduce it
- The affected file, version, or component
- Any relevant examples or proof of concept

Please do not include passwords, private keys, personal information, or other sensitive data in a report.

## Scope

This repository primarily defines the TodoDoneYet Task File Format (`.tddy`) and its supporting documentation and schema.

Security issues involving applications that implement the format should be reported to the maintainers of those applications.
