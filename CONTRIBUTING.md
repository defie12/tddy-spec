# Contributing to TodoDoneYet Task File Format

Thank you for your interest in contributing to the TodoDoneYet Task File Format.

## How to Contribute

1. Read the [format specification](TDDY_FORMAT_SPECIFICATION.md).
2. Review the [JSON Schema](schema/tddy.schema.json).
3. Check the existing examples in the [`examples/`](examples/) directory.
4. Open an issue before making significant changes to the format.
5. For proposed changes, create a pull request with a clear description of the change and its purpose.

## Specification Changes

Changes to the `.tddy` format should preserve backward compatibility whenever possible.

Any change that affects the structure, validation rules, or meaning of a `.tddy` file should update:

- The format specification
- The JSON Schema
- Relevant examples
- The README when necessary

## Pull Requests

Please keep pull requests focused on one change.

Include:

- What was changed
- Why the change is needed
- Any compatibility considerations
- Updated examples or documentation where applicable

Thank you for helping improve the TodoDoneYet Task File Format.
